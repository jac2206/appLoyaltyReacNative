# Plantilla de solicitud SDD

Usar esta estructura para solicitar una funcionalidad a un agente:

```md
## Objetivo

## Dominio y spec afectada

## Comportamiento / criterios de aceptación

## Contratos: API, navegación, persistencia o QR

## Estados UI: carga, vacío, error, éxito y permisos

## Fuera de alcance

## Pruebas y verificación esperada
```

Si falta información que cambia una regla de puntos, contrato externo o requisito legal, detener la implementación y pedirla. Para decisiones internas de bajo riesgo, documentar el supuesto y continuar.

# Skill: UI de recompensas

## Objetivo

Diseñar interfaces móviles claras para consultar y mover puntos sin inducir operaciones equivocadas.

## Aplicación

- Mostrar saldo y puntos con jerarquía visual alta.
- Antes de confirmar acumulación o redención, hacer visibles aliado, sede, importe/puntos y referencia.
- Usar componentes existentes, tokens semánticos y patrones Material descritos en el sistema de diseño.
- Añadir estados de interacción: normal, presionado, deshabilitado, cargando, error y éxito.
- Verificar contraste, tamaño táctil, escalado de texto y etiquetas de accesibilidad.

## Anti-patrones

- Solo `Alert` para errores de formulario.
- Botones que pueden enviar dos veces.
- Errores de QR que expulsan a la persona sin alternativa de reintento.
- Indicadores de progreso fuera del rango 0–100.
